# Graded-Repository

## Purpose
This repository was created for ITE 1100 Tutorial 4. It is used to practice a basic Git and GitHub workflow with a collaborator: making a branch, committing a file, opening a pull request, getting it reviewed, and merging it.

## Collaborators
- Akeem Cruickshank (GitHub: akeemcruickshank1-cmyk), repository owner
- Faizudeen Baigh (GitHub: fai-miau), collaborator and reviewer

## Steps Followed
1. Created a GitHub account and the repository.
2. Added fai-miau as a collaborator in this repository.
3. Created a new branch called Side-Branch.
4. Added a Python file, names.py, that prints my first and last name.
5. Committed the file to Side-Branch with the message "Added sample file for tutorial".
6. Opened a pull request from Side-Branch into main and assigned fai-miau as the reviewer.
7. fai-miau reviewed and approved the pull request.
8. Merged Side-Branch into main after the approval.
